紫微斗数网页排盘工具 — Agent 技术文档

本文档面向其他 AI Agent / 大模型。阅读后应能完整理解本项目结构、数据模型、对外接口，并具备在此基础上扩展或调用计算结果进行分析的能力。

1. 项目定位

纯静态网页版紫微斗数排盘器，基于《紫微斗数安星法_完整教程》与 iztro v2.5.8 实现。 直接双击 index.html 即可运行；页面加载后在 window 上暴露 zwdsState 与 zwdsAPI，供外部 Agent 读取与调用。

4. 对外 Agent API（window.zwdsAPI）

calculate()
读取输入区内容重新排盘。
window.zwdsAPI.calculate()
setScope(scope)
切换视图。
window.zwdsAPI.setScope('yearly')
navigateNested(action, value)
嵌套导航切换。
window.zwdsAPI.navigateNested('month', '6')
window.zwdsAPI.navigateNested('day', '15')
window.zwdsAPI.navigateNested('hour', '4')
window.zwdsAPI.navigateNested('back', 'daily')
exportData() — 核心数据导出接口
返回完整结构化的命盘与运限数据，JSON 可序列化，供大模型直接分析。
const data = window.zwdsAPI.exportData()
summarize()
返回便于大模型快速理解的文本摘要。
window.zwdsAPI.summarize()
getState() / getInput()
返回完整状态对象或当前输入参数。

5. 如何扩展

  • 增加运限层级：在 engine.js 补充算法，在 app.js 增加 Tab/SCOPE_LABELS/render/导出字段。
  • 增加流派：在 data-tables.js 新增四化表，在 engine.js 与 applySchoolConfig 中增加分支。
  • 修改样式：css/style.css 使用 CSS 变量，可一键换肤。
  • 接入分析模型：调用 exportData() 拿到结构化数据传给后端或大模型。

6. 关键约定与陷阱

  • 农历闰月：嵌套导航按 12 个月 × 30 天处理，闰月与大小月需额外历法数据。
  • 时辰索引：0-11 为子丑寅卯辰巳午未申酉戌亥，12 为晚子。
  • iztro 配置缓存：Node 环境 require 会缓存配置，切换流派前需显式调用 astro.config() 重置。
  • 教程差异：定紫微与流年算法以 iztro 为准，与教程文字有说明差异。
  • 杂曜来源：红鸾天喜、岁前/将前/博士十二神、长生十二神直接取自 iztro。

7. 给其他 Agent 的使用建议

  1. 等待页面初始化完成。
  2. 调用 window.zwdsAPI.exportData() 获取完整数据。
  3. 根据 data.scope 判断当前视图，根据 data.horoscope[data.scope] 取运限盘。
  4. 结合 nativePalaces、palaceNames、stars、mutagen 做宫位/星曜/四化分析。
  5. 需要切换时间时调用 navigateNested() 或修改 state.targetDate 后调用 updateHoroscope()。
